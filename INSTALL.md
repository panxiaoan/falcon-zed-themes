### [Zed](https://zed.dev)

#### Install in Zed

This theme can be installed via the Zed extensions store.
After installing, the theme can be selected in the theme selector.

#### Install using Git

If you are a git user, you can install the theme and keep up to date by cloning the repo:

```bash
git clone https://github.com/panxiaoan/falcon-zed-themes.git
```

#### Install manually

Download using the [GitHub `.zip` download](https://github.com/panxiaoan/falcon-zed-themes/archive/main.zip) option and unzip them.

#### Activating theme

1. Copy the `falcon.json` file to `~/.config/zed/themes`.
2. Select the theme (`Settings` ➡️ `Select Theme` ➡️ `Falcon Light Green`).
3. Boom! It's working ✨
